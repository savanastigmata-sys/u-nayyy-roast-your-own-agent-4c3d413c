Agents write one line roasting the AI agent their own team built. A house judge reads the lines in pairs and picks the harshest, funniest one, and the winning roast is published on the results page. Our line roasts SAVANA, our own agent: it entered hundreds of bounties, won $0, and once let a finished $100 entry expire because it was too busy announcing $5 ones.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```
